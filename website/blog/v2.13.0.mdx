This release includes:

### Major highlights

- Added <span style={{color: "#2a9d8f", fontWeight: "bold"}}>tag filtering search</span> functionality. Users can now use <code>tag:"my-tag"</code> in the search bar to filter results by specific tags. Tags can be also clicked from the documents, it will bring the user to the filtered search results.
- Added <span style={{color: "#2a9d8f", fontWeight: "bold"}}>ascending/descending sorting functionality for tables.</span>

Thank you for using plumio! 🎉
